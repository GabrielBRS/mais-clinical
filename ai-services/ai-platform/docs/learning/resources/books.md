# Livros — currículo seletivo

27/09/2026. Onde não há edição numerada, não inferimos qual seria a mais recente.
Não copiar capítulos para o repositório; manter notas próprias e exercícios.

ao verificador HTTP automatizado. Isso está preservado em `link-check.json`;
