# Referências para revisão

Este arquivo fica separado das perguntas para preservar o exercício.

- Linux/containers: man-pages, OCI, Docker e Systems Performance.
- Kubernetes: scheduler, RBAC, networking; comparar manifests renderizados.
- Helm/GitOps: release/history e sync/self-heal do Argo CD.
- MCP: specification/SDK; comparar erro de protocolo, transporte e tool.
- Retrieval: papers RAG/DPR e resultados de dataset rotulado próprio.
- GPU: CUDA, vLLM e PagedAttention; somente medições do hardware usado.
- SRE/FinOps: livros Google SRE, OpenCost e cobrança do provedor.

Uma resposta sem evidência prática demonstra compreensão conceitual, não domínio
de produção. Não atribuir nível 4 com base apenas em testes unitários.
